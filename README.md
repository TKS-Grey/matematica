# matematica
Clasificador de Funciones:
es una pagina web para generar, identificar y visualizar funciones segun sus resultados,

Se asignan valores entre -3 y 3 a b y c,
Se puede ejecútar mediante un servidor local (por ejemplo, la extensión Live Server en VS Code) para evitar restricciones de permisos del navegador al usar el portapapeles

Tecnologías utilizadas:
HTML.
CSS.
JavaScript.
